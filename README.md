# 115/116學年度 彰化區高級中等學校升學資訊導航

專為彰化區國中親師生設計的「高級中等學校升學資訊導航系統」。整合免試入學（大免）、特色招生、各校科別資訊、超額比序規則與升學常見問題，支援手機與電腦全響應式瀏覽。

🔗 **線上網站**：[https://kadotw-lab.github.io/changhua-senior-high-guide/](https://kadotw-lab.github.io/changhua-senior-high-guide/)

---

## 🌟 系統亮點與功能

1. **多元入學管道全覽**：
   - 免試入學（大免）與特色招生管道分類導引。
   - 彰化區各公私立高中、技術型高中（高職）、綜合高中科別資料查詢。

2. **超額比序與積分試算指引**：
   - 整合國中教育會考、均衡學習、多元學習表現（獎懲、服務學習、體適能等）採計規則。
   - 升學重要日程與官方簡章連結快速導航。

3. **現代化響應式 UI 設計**：
   - 基於 Vue 3 與 Tailwind CSS 開發，極速載入、操作流暢。
   - 完美適配手機直式螢幕、平板與桌上型電腦，方便親師生隨時隨地查閱。

4. **單一網頁完整封裝**：
   - 支援離線瀏覽，無需安裝任何複雜伺服器環境。

---

## 🚀 本地開啟方式

直接以瀏覽器開啟專案資料夾內的 `index.html` 或 `彰化區中等學校升學導航.html` 即可完整使用。
